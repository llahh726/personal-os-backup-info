Personal OS Encrypted Backups

A private desktop utility for one owner's encrypted backups to their own Google Drive. This is not a public backup service and does not accept registrations.

Files are encrypted on the owner's computer using restic before rclone transfers the encrypted repository to Google Drive. The recovery password is kept separately.

The Google connection requests only drive.file: access to files created by, or explicitly opened with, this app. It does not request general access to all Drive documents, Gmail, Contacts or Photos.
